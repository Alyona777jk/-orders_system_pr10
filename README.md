# Практична робота №10 (Частина 2): Система замовлень (SQLite Transactions)

Flutter-додаток для обробки замовлень з використанням реляційної БД SQLite, транзакцій та batch-операцій.

## Реалізований функціонал
- **База даних (`orders`, `order_items`, `products`)**: зв'язки `FOREIGN KEY` з `ON DELETE CASCADE`, індекси для оптимізації вибірок.
- **Транзакції**: атомарне створення замовлення з перевіркою залишків, автоматичний `ROLLBACK` при нестачі товару, скасування замовлення з поверненням товарів на склад.
- **Batch-операції**: масове додавання товарів, масове оновлення статусів замовлень, видалення старих виконаних замовлень.
- **Звіти та UI**: перегляд деталей замовлення (`JOIN`), статистика виручки та рейтинг ТОП-5 популярних товарів (`SUM`, `GROUP BY`).
